BELAJAR DENGAN MENGALAMI

Bangun bisnis lokal,
tembus pasar digital.

Jelajahi showroom 3D/VR, uji keputusan harga dan pemasaran, lalu hadapi tantangan bisnis yang dibuat secara dinamis oleh Generative AI.

15–20 menitPengalaman belajar mandiri: eksplorasi produk, keputusan harga, strategi pemasaran, dan tantangan AI.
TAHAP 1 · EKSPLORASI

Masuki showroom produk lokal

Pilih objek 3D untuk melihat karakteristik dan peluang nilai jual. Gunakan mouse/touch untuk melihat sekeliling. Tekan tombol VR pada scene jika perangkat mendukung WebXR.

Klik objek 3D · Gerakkan mouse · VR jika perangkat mendukung
Galendo adalah contoh produk pangan tradisional yang dapat dikembangkan melalui kemasan, cerita asal-usul, variasi produk, dan pemasaran digital.
TAHAP 2 · PENGAMBILAN KEPUTUSAN

Uji keputusan harga dan margin

Angka merupakan data simulasi, bukan harga pasar aktual.

Laba kotor/unitRp12.000
Margin kotor40%
Proyeksi laba kotorRp1.200.000
Ubah biaya atau harga jual, lalu hitung kembali. Pertimbangkan daya beli pelanggan, biaya platform, promosi, dan ongkos kirim.
TAHAP 3 · STRATEGI DIGITAL

Rancang kampanye pemasaran digital

Pilih target pasar, kanal, dan anggaran berdasarkan karakteristik pelanggan.

Rancangan kampanye akan muncul setelah Anda memilih target, kanal, dan anggaran.
TAHAP 4 · GENERATIVE AI

Tantangan bisnis yang dibuat dinamis

GenAI menghasilkan variasi studi kasus sesuai produk, tingkat kesulitan, dan fokus masalah—bukan sekadar chatbot tanya jawab.

API key hanya digunakan sementara di browser. Jangan menaruh API key pribadi di halaman publik. Untuk aplikasi produksi, pindahkan panggilan API ke backend yang aman.

Masukkan API key, pilih tingkat kesulitan dan fokus, lalu tekan tombol untuk membuat studi kasus baru.
